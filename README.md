# News Brief Desk

A Streamlit-based newsroom dashboard for tracking incoming news items, published stories, and publishing turnaround time.

## 🚀 Live Demo

https://vivek65666-news-brief-desk-app-hblsd8.streamlit.app/

## 📊 Dashboard Metrics

- Published today
- Published yesterday
- Average time to publish
- Incoming news items
- Recent published stories

## 🛠️ Tech Stack

- Python
- Streamlit
- SQLite
- Pandas

## ✨ Features

- Newsroom dashboard
- Demo user roles
- Synthetic newsroom dataset
- Published story tracking
- Publishing turnaround metrics
- Incoming news feed
- Recent published stories

## ▶️ Run Locally

Clone the repository:

git clone https://github.com/vivek65666/news-brief-desk.git

Navigate to the project:

cd news-brief-desk

Create and activate a virtual environment:

python -m venv .venv

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
